소장도서 검색 서비스 본 논문이 제안하는 서비스는 클라이언트, Spring Boot 서버, 데이터베이스, 외부 API로 구성된다.
클라이언트는 사용자가 입력한 검색어, 현재위치 또는 선택 주소, 탐색 반경을 서버에 전달한다. 서버는 전달받은 값을 이용하여
도서 검색, ISBN 추출, 도서관 소장 조회를 순서대로 수행한다. 도서 검색 단계에서는 네이버도서 검색 API를 호출하여 후보 도
서 목록을 가져온다. 서버는 응답 데이터에서 ISBN을 추출하고, 해당 ISBN을 도서관 정보나루 API 요청에 사용한다. 도서관 정
보나루 API에서는 해당 도서를 소장한 도서관과 대출 가능 여부를 확인한다. 국가자료종합목록 OpenAPI는 제목, 저자, 출판사
와 같은 서지 정보를 보완하는데 사용한다. 카카오맵 API는 주소 검색과 지도 표시를 담당한다. 본 서비스의 전체 구성도는 그림
1과 같다.
