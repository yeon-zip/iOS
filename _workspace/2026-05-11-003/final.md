III. 소장도서 검색 서비스

본 논문에서 제안한 소장도서 검색 서비스는 클라이언트, Spring Boot 서버, 데이터베이스, 외부 API가 함께 동작하는 구조이다. 사용자가 검색어와 현재 위치 또는 선택한 주소, 탐색 반경을 입력하면 클라이언트가 이를 서버에 전달한다. 이후 서버는 도서를 검색하고, 검색 결과에서 ISBN을 추출한 뒤 그 값을 이용해 도서관 소장 여부를 조회한다.

도서 검색 단계에서는 네이버 도서 검색 API로 후보 도서 목록을 가져온다. 목록에서 확인한 ISBN은 도서관 정보나루 API 요청에 포함되며, 서버는 해당 API의 응답에서 소장 도서관과 대출 가능 여부를 확인한다. 제목, 저자, 출판사 등 서지 정보는 국가자료종합목록 OpenAPI로 보완한다. 주소 검색과 지도 표시는 카카오맵 API가 맡는다. 서비스의 전체 구성은 그림 1에 제시하였다.
